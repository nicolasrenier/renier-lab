Tools & Software

Open-source tools we develop for the neuroscience community.

iDISCO+

A tissue clearing and whole-mount immunolabeling protocol for volume imaging of large intact biological samples using light-sheet microscopy. iDISCO+ enables the visualization of cells, axons, and vasculature across entire organs with subcellular resolution.

Published in Cell (2014, 2016) · Used in labs worldwide

Visit iDISCO.info

ClearMap

An open-source Python framework for automated mapping and analysis of brain data at cellular resolution. ClearMap provides tools for cell detection, vascular network reconstruction (TubeMap), atlas registration, and statistical analysis across whole-brain datasets.

Published in Cell (2016, 2020) · Open source on GitHub

View on GitHub

LAMBADA

The Open Brain Atlas: a comprehensive 3D developmental atlas of the postnatal mouse brain built using tissue clearing and light-sheet microscopy. LAMBADA provides reference templates and spatial transcriptomic annotations for quantitative neuroanatomical studies.

Published in Cell (2025) · Freely accessible online
